# 67 school — ОГЭ Математика 🚀

Личная EdTech-платформа для подготовки к ОГЭ по математике. 
Проект включает в себя базу из 38 уроков, интерактивные задачи с автопроверкой, аналитику ошибок и совместную онлайн-доску для занятий с репетитором в реальном времени.

## ✨ Основные возможности

- **38 готовых уроков**: полный курс по всем темам ОГЭ (Алгебра, Геометрия, Вероятность, Практические задачи).
- **Интерактивный тренажер**: ввод ответов прямо на сайте. Умная проверка (понимает дроби `3/4`, десятичные `0,75`, пары чисел `2; 3`).
- **Фильтрация по сложности**: каждая задача имеет уровень. Внутри урока можно переключаться между «Базовыми» и «Повышенными» (Часть 2) задачами.
- **Совместная доска**: встроенный холст в каждом уроке для рисования в реальном времени (как в Miro). Идеально для созвонов.
- **Прогресс и аналитика**: сохранение результатов в базе, отслеживание статусов уроков («Не начат», «В процессе», «Изучен»), выявление слабых тем по ошибкам.
- **Методичка для преподавателя**: скрытый от ученика блок с планом урока, вопросами и частыми ошибками.

## 🛠 Стек технологий

- **Frontend/Backend**: Next.js 15 (App Router), React 19, TypeScript.
- **База данных и Auth**: Supabase (PostgreSQL, Row Level Security).
- **Realtime (Доска)**: Supabase Broadcast.
- **Стили**: Чистый CSS (`app/globals.css`).
- **Хостинг**: Vercel.

## 🚀 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/oge-math.git
   cd oge-math
Установите зависимости:

bash
npm install
Создайте файл .env.local в корне проекта и добавьте ключи Supabase:

env
NEXT_PUBLIC_SUPABASE_URL=ваша_ссылка_на_проект
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_ключ
Запустите сервер разработки:

bash
npm run dev
Сайт будет доступен по адресу http://localhost:3000.

🗄 Настройка базы данных
В папке supabase/migrations/ находятся SQL-файлы для создания структуры базы данных.
Для запуска выполните их по очереди в SQL Editor в панели управления Supabase:

001_schedule.sql — расписание уроков.

003_progress.sql — отметки о прохождении уроков.

004_attempts.sql — попытки решения задач (для аналитики).

🌐 Деплой
Проект настроен для автоматического деплоя на Vercel.
При пуше в ветку main на GitHub, Vercel автоматически пересобирает и публикует обновления.

Не забудьте добавить переменные окружения (NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY) в настройках проекта на Vercel.

📂 Структура проекта
/app — основные страницы (роутинг Next.js).

/lesson/[id] — страница отдельного урока.

/components — переиспользуемые компоненты (Доска, Проверка задач, Методичка).

/lib — каталог уроков, типы, клиент Supabase.

/supabase — SQL-миграции для базы данных.
